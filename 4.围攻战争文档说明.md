# SiegeWar 战争规则与国家冲突说明
# SiegeWar · Structured Warfare Framework

======================================================================
适用范围：
- 所有涉及国家冲突、围城、占领的行为

本文件用于说明 SiegeWar 在服务器中的法律地位、
战争流程、行为限制与战争结果处理方式。
======================================================================

----------------------------------------------------------------------
一、战争的定义与法律地位
----------------------------------------------------------------------

在 NeoTerra 中，战争被定义为：

- 由国家发起（城镇无法发起）
- 以城镇或领土为目标
- 通过 SiegeWar 系统执行
- 并产生制度化结果的冲突行为

任何不符合上述条件的行为，
均不被视为“战争”，而是非法冲突。

----------------------------------------------------------------------
二、战争主体与权限
----------------------------------------------------------------------

战争主体仅限于国家层级。

允许参与战争的主体包括：

- 国家（Nation）
- 国家正式控制的城镇（Town）

个人、城镇，临时玩家组织
不具备独立发动战争的合法资格。

战争相关权限包括：

- 宣战权
- 防御权
- 战争指挥权
- 战后处理权

上述权限由国家内部制度自行分配。

----------------------------------------------------------------------
三、宣战与围城的基本条件
----------------------------------------------------------------------

国家在发起战争前，必须满足以下条件：

- 双方均存在合法国家实体
- 目标城镇属于敌对国家
- 符合 SiegeWar 的宣战规则
- 未处于休战日的状态

围城（Siege）是战争的起点，
也是战争合法性的核心标志。

未通过 SiegeWar 系统建立围城的行为，
不被视为有效战争行为。

----------------------------------------------------------------------
四、围城阶段与战区规则
----------------------------------------------------------------------

围城建立后，战区将进入特殊状态。

战区规则包括但不限于：

- 限定区域内允许 PVP
- 部分破坏行为被临时授权
- 非参战人员的行为受到限制
- 非战区区域维持原有保护规则

战区的边界与规则由系统自动判定，
任何绕过或滥用战区规则的行为
均视为违规。

----------------------------------------------------------------------
五、战争进程与胜负判定
----------------------------------------------------------------------

SiegeWar 的战争不以击杀数为核心指标。

战争进程主要取决于：

- 战区控制状态
- 城镇防御与支援能力
- 参战方的组织与持续投入
- 战争时间与资源消耗

胜负判定由系统依据既定规则完成，
而非由管理者或玩家临时裁定。

----------------------------------------------------------------------
六、战争中的行为限制
----------------------------------------------------------------------

即使在战争状态下，
以下行为仍然受到限制：

- 无意义的大规模拆毁
- 蓄意破坏非战争目标
- 绕过系统的爆炸或漏洞利用
- 恶意骚扰非参战玩家

战争并不意味着完全失序。
SiegeWar 的设计目的，
是将冲突控制在可管理范围内。

----------------------------------------------------------------------
七、战争结果与制度化结算
----------------------------------------------------------------------

战争结束后，
系统将自动处理以下结果：

- 城镇或领土的控制权变更
- 战败方的制度性惩罚
- 战胜方的合法收益
- 战争状态的解除

所有结果具有制度效力，
不得通过非系统手段撤销或篡改。

----------------------------------------------------------------------
八、战争与国家发展的关系
----------------------------------------------------------------------

战争在 NeoTerra 中不是常态，
而是国家发展中的重要事件。

战争的长期影响包括：

- 国家财政负担增加
- 工业与后勤压力上升
- 国内政治结构变化
- 领土与人口结构调整

不具备持续发展能力的国家，
难以在长期战争中存续。

----------------------------------------------------------------------
九、非法战争与违规行为
----------------------------------------------------------------------

以下行为被认定为非法战争行为：

- 绕过 SiegeWar 的攻击与占领
- 利用漏洞制造“假战争”
- 非法破坏他国城镇
- 借战争之名进行私人报复

此类行为将依据服务器管理规则处理，
其结果不具备任何战争合法性。

----------------------------------------------------------------------
十、最终声明
----------------------------------------------------------------------

SiegeWar 的存在目的并非限制冲突，
而是赋予冲突以秩序、边界与结果。

战争不是混乱的爆发，
而是制度运行的一部分。

所有参与战争的国家与玩家，
默认接受 SiegeWar 所确立的规则体系。

======================================================================
