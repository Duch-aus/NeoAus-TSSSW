NeoTerra 是一个以“城镇”为最小宏观单位进行设计的 Minecraft 服务器。

本服务器并不以个人成长或短期娱乐为核心目标，如果你是极度重视绿色环境的玩家

此服的战争行为和玩家冲突不适合你

在允许的范围内，你可以构建一个具备制度、秩序与长期演化逻辑的虚拟社会系统。

----------------------------------------------------------------------
一、项目总体设计理念
----------------------------------------------------------------------

NeoTerra 的设计遵循以下基本原则：

- 国家是服务器中最高层级的组织形式
- 个人行为必须嵌入制度与规则之中
- 冲突应以结构化、可预期的方式发生
- 生产力决定国家实力，而非个人数值
- 所有系统均服务于长期稳定运行

国家和城镇的玩法不能是孤立存在的模块，
而是一个相互依赖、相互制约的整体系统。

----------------------------------------------------------------------
二、Towny —— 国家与社会结构基础
----------------------------------------------------------------------

Towny 构成服务器的制度基础层。

在 NeoTerra 中，Towny 不仅是领地管理工具，
而是承担了“国家存在形式”的核心功能。

Towny 所定义的内容包括但不限于：

- 城镇与国家的法定结构
- 领土的合法归属与边界
- 土地使用、建设与破坏权限
- 居民、官员与国家职务体系
- 税收、财政与公共资源管理
- 国家之间的外交关系基础

所有行为的“合法性”均源自 Towny 体系。
脱离 Towny 的行为在制度层面视为无效。

----------------------------------------------------------------------
三、SiegeWar —— 结构化国家战争系统
----------------------------------------------------------------------
自我重启项目以来，siegwar就是一直无法逃避的话题
，当我询问时，竟然有那么多人期盼siegwar的回归，

现在,siegwar正式成为服务器主要项目

SiegeWar 是 NeoTerra 中唯一承认的战争机制。

战争在本服务器中将被视为国家战争行为，
而非个人冲突 或 玩家们的即时对抗。

SiegeWar 提供以下能力：

- 国家层级的合法宣战机制
- 围城、占领与防御流程
- 战区规则与行为限制
- 战争结果的制度化结算
- 领土与政治后果的确认

战争不以瞬时胜负为导向，
而是强调持续控制、资源消耗与组织能力。

任何不通过 SiegeWar 体系进行的“战争行为”，
在服务器规则内中将视为“非法”，视为玩家冲突

出现任何战争破坏行为，将会受到审判

----------------------------------------------------------------------
四、Slimefun —— 工业体系与国家生产力
----------------------------------------------------------------------

Slimefun 构成服务器的工业与科技层。

该系统用于模拟从基础生产到高度工业化的
长期发展过程，而非单纯的个人能力扩展。

Slimefun 在 NeoTerra 中主要承担：

- 工业化资源生产
- 自动化加工与能源系统
- 高阶材料与技术解锁
- 国家级基础设施建设支持

工业体系的规模与效率，
直接影响国家的财政能力、军事潜力与发展速度。

在服务器的设计逻辑中：
生产力是国家竞争的核心变量。

----------------------------------------------------------------------
五、系统协作与整体架构
----------------------------------------------------------------------

NeoTerra 的核心系统分工明确：

Towny：
- 提供国家与社会结构
- 确立法律、领土与权力边界

Slimefun：
- 提供工业能力与技术发展
- 决定国家的物质基础

SiegeWar：
- 处理国家间的冲突
- 决定领土与权力的变动结果

三者共同构成一个闭环系统：

制度 → 生产 → 冲突 → 重组 → 再发展

任何单一系统都无法独立运作。

----------------------------------------------------------------------
六、你（玩家）在服务器体系中的位置
----------------------------------------------------------------------

NeoTerra并没有强迫所有玩家加入或创立城镇国家，

你可以成为自由民，隐居在山间，或者成为山间土匪，进行抢劫的非法行为

但是一旦你加入，就是Towny体系中的组成部分，将会被受制

玩家的主要发展方向包括：

- 行政与管理职能
- 工业与生产体系建设
- 军事组织与战争执行
- 国家战略与外交参与

个人行为的价值，
取决于你在结构中的位置与作用。

----------------------------------------------------------------------
七、运行与行为规范原则
----------------------------------------------------------------------

- 所有领土与建设行为受 Towny 管理
- 所有战争行为必须通过 SiegeWar 系统，否则一律为“非法战争”
- 工业设施属于城镇或国家资产范畴
- 禁止公民绕过制度的破坏、掠夺或冲突，除非你本身是自由民，但你将不会受到任何保护
- 服务器严禁对自然地形的恶意破坏，严禁各种炸服机器
- 国家城镇管理与规则优先于你的个人意志（仅限于你加入的情况）

服务器以稳定性与可持续性为最高目标。

----------------------------------------------------------------------
八、项目定位声明
----------------------------------------------------------------------

NeoTerra 并非为所有玩家设计。

本服务器不追求：
- 快速成型
- 即时满足
- 高频重置

而是面向希望参与：
- 国家构建过程
- 社会结构演化
- 制度约束下竞争
- 长周期发展的玩家群体

这是一个需要时间、耐心与协作的世界。如果你不愿意接受国家城镇兴衰灭亡

或者因为无理由的战争而愤怒，请你退服，你并不适合该服务器
